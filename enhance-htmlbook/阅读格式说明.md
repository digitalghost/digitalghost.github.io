# Enhanced HTML 与 PDF 阅读版说明

本项目将规则书/模组原文制作为两种阅读格式：**Enhanced HTML**（增强网页版）和 **PDF**（便携文档版）。两种格式各有优势，互为补充，适合不同阅读场景。

---

## Enhanced HTML — 增强网页版

适合**桌面/平板浏览器阅读**，注重交互体验与视觉沉浸。

### ✦ 核心特性

| 特性 | 说明 |
|---|---|
| **侧边栏章节目录** | 左侧固定目录树，h1/h2/h3 三级结构可折叠展开，点击即跳转 |
| **滚动位置联动** | 阅读时侧边栏自动高亮当前章节，始终知道自己读到哪 |
| **明暗主题切换** | 一键切换亮色/暗色模式，夜间阅读不刺眼 |
| **阅读进度条** | 页面顶部细线实时显示阅读进度 |
| **返回顶部按钮** | 右下角悬浮按钮，一键回到开头 |
| **响应式布局** | 宽屏侧边栏常驻，窄屏（手机/平板）自动折叠为汉堡菜单 |
| **纸张纹理背景** | 模拟实体书纸张质感，减少屏幕疲劳 |
| **浏览器内搜索** | Ctrl+F 全文搜索，快速定位关键词 |
| **自由缩放** | 浏览器缩放无限制，字体大小随心调 |

## PDF — 便携文档版

适合**离线阅读、标注存档、打印及电子书阅读器**。

### ✦ 核心特性

| 特性 | 说明 |
|---|---|
| **PDF 书签目录** | 阅读器侧边栏显示完整章节目录（同 HTML 侧边栏结构），点击跳转 |
| **完全离线** | 单文件包含全部文字与嵌入字体，无需网络、无需浏览器 |
| **跨平台一致** | 在任何设备/系统上排版完全一致，不会因浏览器差异变形 |
| **标注与批注** | PDF 阅读器支持高亮、下划线、批注、书签，适合深度学习 |
| **打印友好** | 白底黑字，A4 页面，可直接打印成纸质版 |
| **电子书阅读器兼容** | 可导入 Kindle、Boox 等电纸书设备阅读 |
| **智能宽表处理** | 多列表格自动检测 → 等分列宽 + 强制断行，永不超出页面边界 |
| **跨页表头重复** | 长表格跨页时自动重复表头，翻页不迷列 |
| **章节分页** | 每章（h2）自动从新页开始，结构清晰 |
| **页码显示** | 每页底部居中页码，方便引用「第 X 页」 |

### ✦ 与其他 PDF 的区别

市面上常见的「网页直接打印为 PDF」方案存在以下问题，本项目已全部解决：

| 常见问题 | 本项目处理方式 |
|---|---|
| 侧边栏、按钮等 UI 元素也被印入 PDF | print.css 自动隐藏所有浏览器 UI |
| 网页背景色/纹理在 PDF 中脏乱 | 强制白底黑字，关闭纹理叠加 |
| 字体丢失导致乱码/豆腐块 | 嵌入系统级中文字体（苹方），确保可读 |
| PDF 没有目录书签 | 自动从 h1/h2/h3 提取 200+ 书签 |
| 宽表格超出页面右边界 | 智能检测 → 等分列宽，强制换行 |
| 表格标题孤零零占一页留白 | 允许表格跨页 + 标题粘连后续内容 |

## 格式选择建议

| 场景 | 推荐格式 |
|---|---|
| 日常桌面浏览器阅读 | **Enhanced HTML** |
| 夜间/暗光环境阅读 | **Enhanced HTML**（暗色主题） |
| 快速搜索规则关键词 | **Enhanced HTML**（Ctrl+F） |
| 手机/平板阅读 | **Enhanced HTML**（响应式） |
| 离线阅读（无网络） | **PDF** |
| 导入电纸书（Kindle 等） | **PDF** |
| 打印纸质版 | **PDF** |
| 深度研读、做标注 | **PDF** |
| 引用页码范围 | **PDF** |
| 长期存档 | **PDF** |

## 技术实现

- **Enhanced HTML**：由 Markdown 通过自定义工具转为 HTML，搭配手写 CSS（亮/暗双主题、纸张纹理、响应式侧边栏）和原生 JavaScript（目录生成、滚动联动、进度条）
- **PDF**：通过 Python + WeasyPrint 从 HTML 自动生成，print.css 控制排版，脚本自动标记宽表、生成书签。原 HTML 文件零修改
- **转换工具**：`html2pdf.py`（项目根目录），`source .venv/bin/activate && python html2pdf.py --all` 即可批量转换

---

> 两种格式的内容完全一致，原 HTML 文件保持不变。PDF 是 HTML 的派生输出，不会对原文造成任何污染。
