    欢迎来到启示录！（WELCOME TO THE APOCALYPSE!）

    “我要在天上地下显示神迹：有血、有火、有烟柱。日头要变为黑暗，月亮要变为血，这都在耶和华大而可畏的日子未到以前。”
    ——《约珥书》2:30-31

    《血月启示录（Blood Moon Apocalypse）》是一款生存探索游戏，背景设定在被超自然生物席卷的世界。玩家需在末世环境中搜集资源、建造行动基地以求生存。

    末世之初，血月（Blood Moon） 突然降临——天文学家本应是普通满月，因此人们视其为末日征兆。黑夜无限延长，世界陷入永恒的赤色暮光，血月如赤色巨眼悬于天际，审判人类罪孽。全球暴力袭击、被附身者目击报告激增。人们很快意识到，血月不只是预兆，更是邪恶降临的信使。

    袭击迅速升级，恶魔力量占据大量人类躯体，将其变为嗜血无情的杀手。被附身者拥有非人力量、速度与韧性，几乎无法阻挡。政府与军方试图遏制，但无力应对超自然威胁。恐慌与混乱蔓延，人们为求生开始劫掠与暴力。传言称血月打开了地狱之门，释放恶魔大军。它们占据最脆弱人类的躯体，作为执行意志的容器。数周后，幸存者抱团求生，在危险新世界寻找生路。

    在游戏中，你将扮演一名幸存者，在恶魔降临的末世中挣扎求生。探索世界时，你必须面对成群被附身者——毫无理智、只为杀戮的野蛮野兽。更糟的是，被附身者虽是主要威胁，却并非唯一……每种生物都有独特能力与优势，你必须调整策略与战术应对。

    为了生存，你必须搜集食物、水源、武器等资源。游戏包含制作系统（crafting system），可用搜集资源制作物品。制作等级越高，可造武器与物品越强。

    所有行动都围绕基地（Home Base）展开，你必须用防御建筑与陷阱加固基地——恶魔无论你是否准备好都会来袭。基地可逐步升级，解锁制作台、医疗中心等设施。你将从基地出发，探索周边区域，搜集对抗感染者潮所需的一切资源。

    被附身者毫无理智，只受暴力驱使，无法沟通。传言存在更强大的被附身者，但你尚未遇见——切勿放松警惕。它们虽无脑，却极度残暴，且数量以十亿计。背起背包、拿起武器，为生命而战吧——这是启示录，没人会来救你。

    你的幸存者（YOUR SURVIVOR）

    在《血月启示录》中，你操控一名末日幸存者。角色可设定为任意年龄、性别、种族，外观可自由想象，不影响游戏数值。本章将介绍角色能力与成长方式。

    属性（Attributes）

    幸存者由**属性（Attributes）**定义，通过属性与世界互动、应对末世挑战。属性越高，生存几率越大。

    • 体质（Constitution, CON）：承受物理压力与伤害的能力，直接决定可承受创伤数——等于体质值。初始3点。
    • 敏捷（Dexterity, DEX）：灵巧与手部操作能力，也控制枪械远程攻击。初始2点。
    • 毅力（Grit, GRI）：勇气与决心，往往决定生死。毅力为特殊货币：可重掷任意失败判定。掷出全6获得1点毅力；掷出全1立刻失去1点毅力。初始3点。
    • 智力（Intelligence, INT）：心智任务与快速思考的能力，主导搜集（scavenging）与制作（crafting）。初始2点。
    • 力量（Strength, STR）：角色力量值，决定举重、破坏等体力表现，影响负重，最关键的是决定近战武器使用能力。初始2点。

    特长（Perks）

    **特长（Perks）是独特能力与天赋，让幸存者在特定场景获得优势。通过经验值（XP）购买，建造图书馆（Library）**后解锁。每个特长花费10 XP。

    • 精准（Accurate）：弹药消耗-1，最低为1。
    • 敏捷（Agile）：+1敏捷，可重复选取，但每次花费翻倍。
    • 强壮（Brawny）：+1力量，可重复选取，但每次花费翻倍。
    • 聪慧（Bright）：+1智力，可重复选取，但每次花费翻倍。
    • 铜墙铁壁（Built Like a Brick Wall）：+1体质，可重复选取，但每次花费翻倍。
    • 冲锋（Charge）：战斗中难度值+1，但每次判定可忽略1个掷出的1。
    • 巧手（Handyman）：制作判定时可重掷1颗骰子。
    • 勇敢（Plucky）：最大毅力+1。
    • 拾荒者（Scrounger）：搜集判定时可重掷1颗骰子。
    • （原文残缺）：载具旅行时燃料消耗-1。

    初始装备（Starting Gear）

    角色开局在基地拥有以下物品：

    • 6份口粮（Rations）
    • 1把格斗刀（Combat knife）
    • 1把手枪（Pistol）
    • 3发弹药（Ammo）
    • 3份医疗物资（Medical Supplies）
    • 10份制作材料（Crafting Supplies）

    物品与资源携带（Carrying Items and Resources）

    负重上限由力量决定：可携带物品数=力量×10。已装备武器不占空间。

    经验值获取（Earning Experience Points, XP）

    提升角色需积累经验值，通过探索获取：

    1. 成功探索1个地点（击败感染者 或 获取任意资源）→ 1 XP
    2. 随机事件触发战斗并存活 → 1 XP

    游戏玩法（PLAYING THE GAME）

    “羔羊揭开第六印的时候，我又看见地大震动，日头变黑像毛布，满月变红像血。”
    ——《启示录》6:12

    你的目标很简单：尽可能活下去。为此你需要探索周边，搜集建造完善基地的材料，同时击退感染者潮。本章将介绍成为优秀幸存者的所有规则。

    核心机制（The Core Mechanic）

    所有行动都需要技能判定（skill check）：

    1. 从属性对应的骰子池选择若干**六面骰（D6）**掷出
    2. 计算总数，达到或超过**难度值（Threshold Number, TN，通常为5）**则判定成功
    3. 若总数低于难度值则判定失败，战斗中会受伤，或承受其他负面效果
    4. 关键规则：掷出任意1则直接判定失败，无视总点数
    5. 可选择“冒险”追加骰子，但会提升掷出1的概率

    常见技能判定：

    • 制作：智力
    • 抵抗伤害：体质
    • 远程战斗：敏捷
    • 近战战斗：力量
    • 搜集：智力

    示例：理查德探索基地附近商场，遭遇普通感染者，难度值5。他手持斧头，用敏捷（3点）攻击。他先掷1颗骰子得4，差一点成功；追加1颗，不幸掷出1，判定失败，被咬伤受伤。

    战斗（Combat）

    战斗遵循普通技能判定规则：用对应属性对抗难度值（默认5）。无论判定是否成功，对手都会被击败；失败则你受到1点创伤。

    幸存者可承受创伤数=体质值。

    远程武器（枪械）相比近战有优势：战斗判定掷出6可抵消1个1。这是多数幸存者偏爱枪械的原因，即便需要持续补充弹药。枪械唯一缺点是噪音：每次使用枪械战斗，围攻潜力（Siege Potential）+1，会吸引感染者追踪至基地。

    治疗（Healing）

    • 基地治疗：在基地休息一整天 + 1份医疗物资 → 治愈1点创伤，治疗期间无法进行其他活动
    • 野外急救：花费3份医疗物资 + 智力判定（难度值6）→ 治愈1点创伤，每次探索只能用1次

    游戏回合（The Game Turn）

    游戏以回合为单位，1回合=1整天，每天只能执行1项行动：

    1. 探索（Explore）：前往新地点，寻找有价值物品
    2. 制作（Craft）：花费一整天制作实用物品
    3. 建造（Build）：搭建新设施
    4. 基地劳作（Work Base）：产生1点劳动力（Labor）

    强制规则：幸存者每天必须消耗1份口粮，否则会陷入饥饿惩罚。

    你的基地（Your Home Base）

    金窝银窝不如自己的狗窝。你的基地可能是几间安全公寓、计划加固的农场，或是有潜力的加油站。无论曾经是什么，它都是你末世生存的唯一希望。

    基地初始可存储100件物品（制作材料、弹药、口粮、装备等），可通过建造**储藏棚（Storage Shed）**升级扩容。

    设施（Facilities）

    设施是末世成功的关键，必须花费资源（电子元件/制作材料）与劳动力建造。

    设施列表

    • 自动炮塔（Automatic Turret）：劳动力3 / 资源10电子元件+20制作材料；基地被围攻时立即击杀D4感染者，消耗2弹药
    • 车库（Garage）：劳动力5 / 资源10电子元件+30制作材料；解锁载具，探索旅行时间减半（最低1天），每天旅行消耗1燃料，围攻潜力+1/天，额外携带20件物品
    • 花园（Garden）：劳动力10 / 资源30制作材料；每3天被动产出1份口粮
    • 发电机（Generator）：劳动力5 / 资源30电子元件+50制作材料；1燃料兑换1劳动力，使用每天围攻潜力+1
    • 图书馆（Library）：劳动力5 / 资源10电子元件+30制作材料；解锁特长学习
    • 医疗诊所（Medical Clinic）：劳动力10 / 资源30电子元件+50制作材料；花费3医疗物资即可立即治愈1点创伤，无需休息一整天
    • 储藏棚（Storage Shed）：劳动力1 / 资源20制作材料；基地存储量+100

    • 工坊（Workshop）：劳动力2 / 资源10电子元件+20制作材料；可制作装备栏所有物品，花费2制作材料造1弹药；制作需智力判定（难度值5），失败仅浪费一天

    围攻（Siege）

    感染者会被基地活动吸引，用**围攻潜力（Siege Potential）**追踪。

    围攻潜力增加规则

    • 制作每天+1
    • 部分设施使用后固定增加
    • 无围攻的每天+1
    • 载具探索每天+1
    • 部分随机事件固定增加

    围攻结束后围攻潜力重置为0。

    围攻判定

    每周必须进行围攻判定：掷D10+围攻潜力，结果≥25则触发围攻。

    围攻流程

    1. 感染者数量=围攻潜力÷2（向上取整）
    2. 获得D6次免费攻击，失败不受伤
    3. 击退所有感染者即成功
    4. 存活奖励：+D6劳动力

    探索启示录世界（Exploring the Apocalypse）

    迟早你必须离开安全基地，外出寻找物资。核心目标是搜集生存关键资源。

    资源（Resources）

    • 口粮（Rations）：食物与水源，维持生存。3天不进食，之后每饿1天，所有判定总点数-对应天数
    • 弹药（Ammo）：枪械使用必需品，每次射击消耗1发；无弹药只能用近战
    • 燃料（Fuel）：载具旅行必备，每天旅行消耗1燃料
    • 电子元件（Electronics）：制作高级物品的电气组件
    • 医疗物资（Medical Supplies）：治疗创伤，1份治愈1点创伤
    • 制作材料（Crafting Supplies）：制作/修复工具、建筑的基础材料

    探索流程（Exploration）

    1. 将基地标记在探索纸中央
    2. 生成地点连接路径（无游戏影响）
    3. 掷随机方向表确定下一个地点方向
    4. 选择路径进入新地点
    5. 掷地点表获取地点信息，成功**搜集判定（智力，难度值5）**获得资源
    6. 无法携带的物品可留下，但返回时掷D6：5+则被他人拿走

    探索随机事件（Random Exploration Events）

    进入新地点时掷骰触发事件。

    旅行（Traveling）

    往返已探索地点时，每个地点仅需半天（向上取整）。

    示例：尤里距离基地3个地点，返程需2天（3×0.5=1.5→向上取整为2）。

    装备（Gear）

    生存几率直接取决于装备。装备通过制作或搜集获得。

    武器（Weapons）

    • 棒球棍：制作需7制作材料；攻击时可重掷1颗骰子，第二次为最终结果
    • 格斗刀：制作需5制作材料；战斗中除1外任意骰子+1
    • 十字弩：制作需10制作材料；拥有枪械优势但不增加围攻潜力
    • 手枪：制作需10制作材料；战斗中除1外任意骰子+1
    • 霰弹枪：制作需15制作材料；攻击时可重掷1颗骰子，第二次为最终结果
